# Calculator Project Requirements

## 1. Giới thiệu

Ứng dụng máy tính đơn giản hỗ trợ:

- cộng
- trừ
- nhân
- chia

Frontend sử dụng React.
Backend sử dụng Node.js Express.

---

## 2. Functional Requirements

### FR-1

Người dùng nhập số thứ nhất.

### FR-2

Người dùng chọn phép toán.

### FR-3

Người dùng nhập số thứ 2.

### FR-4

Hệ thống trả về kết quả.

### FR-5

Hệ thống lưu lịch sử tạm thời

---

## 3. Non-functional Requirements

- UI dễ sử dụng
- Response < 1s
- Không reload trang
- Responsive
